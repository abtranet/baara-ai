# Baara AI — Referral Funnel Landing Page

Bilingual (French/English) high-converting landing page for **Baara AI**, referring domain experts from 100+ supported countries to the US platform **Mercor**.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- TypeScript

## Configuration
Copy `.env.example` to `.env.local`:
```bash
NEXT_PUBLIC_MERCOR_REFERRAL_LINK=https://t.mercor.com/S0VZG
NEXT_PUBLIC_MERCOR_REFERRAL_CODE=S0VZG
NEXT_PUBLIC_WHATSAPP_NUMBER=19173992172
```

## Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
